# Disaster Relief & Rescue Coordination System

A console based Disaster Relief & Rescue Coordination System developed in **C** to assist emergency response operations during disasters. The system helps manage incidents, victims, rescue teams, shelter camps, and relief supplies through a menu-driven interface.

---

## Features

###  Incident Management
- Log new incidents
- Search incidents by ID
- View all incidents
- Mark incidents as resolved
- Display high-severity incidents
- Generate city risk/severity graph

### Victim Registry
- Register victims
- View all registered victims
- Search victims by ID
- Search victims by keyword
- Update victim status
- Display victim summary

###  Rescue Team Management
- Add rescue teams
- View rescue teams
- Search rescue teams by ID or name
- Automatically assign the nearest available rescue team
- Track rescue team availability
- Generate performance reports

### Supply Management
- Add food supplies
- View inventory
- Monitor low-stock items
- Distribute supplies to shelter camps
- Manage special supply requests

###  Shelter Camp Management
- Register shelter locations
- Create shelter camps
- Assign victims to camps
- Manage camp capacity
- Handle victims with special needs
- Display camp availability

## How to Compile

### Linux / macOS

```bash
gcc main.c -o DisasterReliefSystem
./DisasterReliefSystem
```

### Windows

```bash
gcc main.c -o DisasterReliefSystem.exe
DisasterReliefSystem.exe
```
